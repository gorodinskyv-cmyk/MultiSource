# Lampa MultiSource v1.0.0

Незалежний плагін для застосунку **Lampa**, який надає багатоджерельний пошук
та відтворення **прямих** відеопотоків (HLS `.m3u8`, MP4, WebM, MPEG-DASH `.mpd`,
якщо відповідний формат підтримує встановлений програвач).

## Файли

- `lampa-multisource.js` — **основний, самодостатній JS-файл**, містить адаптер UASerials.
- `sources/example-json.js` — шаблон другого провайдера (не підключається автоматично).
- `tests/smoke.test.js` — базові тести API та валідації URL.

## Як встановити у Lampa

1. Розмістіть `lampa-multisource.js` на власному HTTPS-хостингу, який віддає JS як
   `application/javascript` (наприклад, GitHub Pages). Публічний файл повинен бути
   доступний за `https://.../lampa-multisource.js`.
2. У Lampa відкрийте **Налаштування → Розширення/Плагіни → Додати плагін**.
3. Вставте **повне HTTPS-посилання на JS**, збережіть і перезапустіть Lampa.
4. Відкрийте картку фільму або серіалу та натисніть **▶ MultiSource**.
5. Виберіть результат пошуку, потім пряме відео або «Відкрити на сайті».

Якщо Lampa не показує кнопку, перевірте завантаження скрипта та сумісність
конкретної версії Lampa (обробник події `full/complite`).

## UASerials — можливості та обмеження

Пошук: `https://uaserials.com/search/{назва}/page/1/`.

- Адаптер шукає сторінки `.html`, співставляє назви, завантажує вибрану сторінку.
- Прямі адреси з HTML5 `<video>`, `<source>`, JSON-даних і відкритих iframe можуть
  відтворюватися в Lampa.
- **Захищені, зашифровані або динамічні плеєри UASerials НЕ підтримуються.**
  Не реалізовано декодування Tortuga / токенів, обхід DRM, CORS, Cloudflare,
  захисних механізмів або перенаправлення через сумнівні проксі.
- Якщо прямий потік не знайдено, доступна дія «Відкрити на сайті»;
  залежно від телевізора вона відкриває браузер або копіює URL.
- На браузерах, де сайт не надає `Access-Control-Allow-Origin`, пошук не буде
  працювати без дозволеного API / власного авторизованого серверного адаптера.
- **Зовнішню доступність прямого відео у реальній Lampa не перевірено.**
  Те, що сторінка доступна на сайті, не означає, що відео доступне плагіну.

## Нові джерела

Плагін надає глобальний реєстр `window.LampaMultiSource`:

```js
window.LampaMultiSource.registerSource({
  id: 'my_provider',                 // унікальний латинський ідентифікатор
  name: 'Мій сервіс',
  search: function(movie, api) {     // Promise<Array<{title, url, year, id}>>
    return Promise.resolve([]);
  },
  getStreams: function(item, api) {  // Promise<{streams, pageUrl}>
    return Promise.resolve({streams: [], pageUrl: item.url});
  }
});
```

Кожен `stream` має `{title, url, season?, episode?, voice?, subtitles?, headers?}`.
Значення `url` має бути **прямою HTTPS-адресою** відеофайлу або HLS/DASH-маніфесту.

Щоб додати провайдер, створіть окремий JS за прикладом `sources/example-json.js`,
розмістіть на HTTPS-сервері та завантажте **після** основного файлу.
Якщо Lampa завантажує плагіни в непередбачуваному порядку, об'єднайте обидва JS
в один файл з основним скриптом першим.

Функції: `registerSource`, `unregisterSource`, `listSources`, `request`, `extractDirect`,
`helpers`, `open(movie)`.

## Технічні зауваження

- Файл написаний без сторонніх залежностей (крім API Lampa / jQuery, вже наявних у Lampa).
- Плагін не імпортує код з kinohub.uk і не використовує сторонні аккаунти/ідентифікатори.
- Він не запускає сторонній JavaScript, знайдений на сторінках сайтів.
- Дотримуйтесь авторських прав і правил використання джерел.
- Зміни структури HTML на сайті можуть вимагати оновлення парсера.

## Перевірка

```bash
node --check lampa-multisource.js
node tests/smoke.test.js
```

Це локальні перевірки JS, не end-to-end тест на Android/Smart TV.
